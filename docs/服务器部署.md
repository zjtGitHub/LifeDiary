# 服务器部署

- 服务器：`ubuntu@129.211.50.155`
- 访问地址：<http://129.211.50.155:8080>
- 代码仓库：`/home/ubuntu/code/LifeDiary`
- 发布版本：`/var/www/lifediary/releases/`
- 当前发布：`/var/www/lifediary/current`（符号链接）
- 上一个版本：`/var/www/lifediary/previous`（第二次发布后创建）
- Nginx 配置：`/etc/nginx/sites-available/lifediary`

代码和构建依赖保存在代码目录，Nginx 仅提供构建后的静态文件。原网站 `xibao.zjt666.top` 使用 `/var/www/html`，与本项目分开。

## 更新发布

先将代码同步到服务器仓库，再执行：

```bash
cd /home/ubuntu/code/LifeDiary
bash scripts/deploy.sh
```

脚本自动加载现有 nvm（如有需要），执行 `npm ci` 和 `npm run build`，构建成功后创建独立发布目录，并原子切换 `current`。发布静态文件需要 sudo 权限。更新静态文件无需重启 Nginx。

服务器仓库的 origin 已配置为 `https://github.com/zjtGitHub/LifeDiary.git`，当前仓库可通过 HTTPS 无认证读取。此前使用 SSH 地址时，服务器没有 GitHub SSH 私钥，导致 `Permission denied (publickey)`；改用 HTTPS 后已验证 `git pull --ff-only origin main` 成功。若以后仓库改为私有，需要另外配置读取权限。

首次部署通过 Git bundle 传入本地仓库，保留提交历史。后续需先在开发机提交并推送代码，再在服务器执行 `git pull --ff-only origin main`。拉取前用 `git status --short` 检查工作区；如有未提交改动，需先备份并处理，避免覆盖冲突。

## 首次发布并配置 Nginx

先在代码目录执行 `npm ci --no-audit --no-fund && npm run build`。首次服务器构建已由部署过程完成。随后在服务器已登录的交互终端执行：

```bash
cd /home/ubuntu/code/LifeDiary
bash deploy/setup.sh
```

该脚本需要 sudo 权限，根据服务器的 sudo 配置可能提示输入密码。脚本发布已构建的 `dist`（调用 `bash scripts/deploy.sh --publish-only`），启用本项目的独立 Nginx 配置，通过配置检查后重新加载 Nginx。若本项目配置已经存在，脚本会退出，避免覆盖。配置检查失败时会取消启用新站点。

腾讯云安全组需要允许入站 TCP 8080：在该实例绑定的安全组中添加入站规则，类型为“自定义”，来源为 `0.0.0.0/0`，协议端口为 `TCP:8080`，策略为“允许”。若实例属于轻量应用服务器，则在实例的“防火墙”页面添加 TCP 8080 规则。参考[腾讯云安全组说明](https://cloud.tencent.com/document/product/213/112614/)。

首次检查时服务器 UFW 未启用，Nginx 已监听 `0.0.0.0:8080` 和 `[::]:8080`。若服务器之后启用了 UFW，也需要允许该端口。服务器内访问正常而公网超时，应优先检查腾讯云侧的安全组或防火墙规则。

## 回滚

确认 `previous` 指向需要恢复的版本，然后执行：

```bash
sudo readlink /var/www/lifediary/previous
rollback_link="/var/www/lifediary/.rollback-$$"
sudo ln -s "$(sudo readlink /var/www/lifediary/previous)" "$rollback_link"
sudo mv -Tf "$rollback_link" /var/www/lifediary/current
```

发布目录会保留，回滚不需要重建代码。回滚只切换静态文件，不会改变浏览器数据。

## 验证与日志

```bash
curl -I http://127.0.0.1:8080/
curl -I http://127.0.0.1:8080/calendar
sudo tail -n 50 /var/log/nginx/lifediary.error.log
```

日记、清单和股票备忘录保存在访问者浏览器的 IndexedDB 中，不会自动上传或同步到服务器。原本在本地开发地址保存的数据需要先导出备份，再到新地址导入。更换域名、协议或端口会使用另一份浏览器存储。

普通公网 HTTP 地址不支持 Service Worker，离线 PWA 功能需要后续绑定域名并启用 HTTPS。
